# Project Roadmap - MyTradeJournal

This document tracks the planned enhancements and future features for the MyTradeJournal application.

## 🚀 Position Size Calculator Enhancements
*Goal: Transition the calculator from a standalone tool to an integrated workflow component.*
- [ ] **Live ATR Integration**: Fetch current ATR automatically for a given symbol using a market data API.
- [ ] **Risk-Reward Projection**: Add target RR input to visualize potential profit vs. risk.
- [ ] **Strategy Presets**: Create presets for different styles (e.g., Scalping 1.5x, Swing 3.0x).
- [ ] **Trade-to-Journal Shortcut**: Add a "Log this Trade" button to push calculated values directly into the Trade Form.

## 📊 Advanced Analytics
*Goal: Provide deeper psychological and mathematical insights into trading performance.*
- [ ] **Psychology Correlation**: Implement "Mindset" tags and analyze P&L correlation with emotional states.
- [ ] **Equity Curve Stress Testing**: Add Monte Carlo simulations to predict probability of drawdowns.
- [ ] **Trade Distribution Heatmap**: Build a time-of-day/day-of-week profitability heatmap.
- [ ] **Mistake Tracking**: Create a tag-based system for specific errors (e.g., #FOMO, #RevengeTrade) with a dedicated report.

## ✨ UX & Technical Polish
*Goal: Transform the application into a professional-grade trading terminal.*
- [ ] **PWA (Progressive Web App)**: Enable offline logging and mobile installation for instant trade entry.
- [ ] **Global Dark Mode**: Implement a high-contrast dark theme optimized for trading terminals.
- [ ] **Keyboard Shortcuts**: Add "Power User" hotkeys (e.g., `Ctrl+N` for new trade, `Ctrl+K` for calculator).
- [ ] **Customizable Dashboard**: Allow users to rearrange analysis cards via drag-and-drop.
